# محفظة أعمال محلل بيانات | Data Analyst Portfolio

مرحباً، أنا محمد — صحفي ومحلل سياسي متمرس، أعمل حالياً على التحول المهني نحو مجال **تحليل البيانات**، مستنداً إلى خلفيتي في البحث والتحليل الدقيق للمعلومات، ومطوّراً مهاراتي التقنية من خلال دورات متخصصة ومشاريع تطبيقية.

يوثّق هذا المستودع مسيرتي التدريبية ومشاريعي العملية في تحليل البيانات، وهو جزء من رحلتي التي أشاركها أيضاً عبر مدونتي المتخصصة [The Smart Analytics](https://the-smartanalytics.com).

---

## 🧭 نبذة عني

- خلفية مهنية في الصحافة والتحليل السياسي، مع مهارات بحثية وتحليلية عالية.
- أتدرّب حالياً ضمن مسار **Cisco Networking Academy** لبناء أساس تقني متين.
- أوثّق كل ما أتعلمه بشكل عملي عبر مشاريع حقيقية ومقالات تعليمية.

---

## 🛠️ المهارات التقنية

| المجال | الأدوات والمهارات |
|---|---|
| **تحليل البيانات بـ Excel** | الدوال المتقدمة (`SUMIFS`, `COUNTIF`, `INDEX/MATCH`)، الجداول المحورية، الرسوم البيانية |
| **SQL** | الاستعلامات الأساسية (`SELECT`)، التجميع، الـ `JOINs`، وصولاً إلى المواضيع المتقدمة (`Window Functions`, `CTEs`) |
| **Python** | تحليل ومعالجة البيانات (قيد التطوير) |
| **Power BI** | بناء لوحات معلومات تفاعلية (قيد التطوير) |
| **مهارات مساندة** | التفكير التحليلي، كتابة التقارير، البحث والتحقق من المصادر |
